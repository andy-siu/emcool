0. download silicon labs cp210x USB driver for windows
1. Download IDF v6.1 from espressif.com

2. theres a powershell installed on desktop.  Thats what we will use.
 IDF_v6.1_Powershell
3.  cd emcool; 
    idf.py --preset esp32 build
    idf.py --preset esp32 flash
    idf.py --preset esp32 -p COM5 monitor or idf.py --preset esp32 monitor

    For an ESP32-S3 board, use --preset esp32s3 instead.

4. Or use the make shortcuts instead of step 3. Windows doesn't come with make,
   so install it once, then open a new PowerShell:
    winget install ezwinports.make

    cd emcool
    make build      (or just: make)
    make flash      (or: make flash PORT=COM5)
    make monitor    (or: make monitor PORT=COM5)

   Add CHIP=esp32s3 for an ESP32-S3 board, e.g. make flash CHIP=esp32s3.

    make menuconfig   change the options, such as the pins (emcool menu)
    make defaults     forget the build's options; the next build uses the defaults

   A build keeps the options (pins included) it was first made with, in
   build\<chip>\sdkconfig. After the defaults change, run make defaults
   (with CHIP=esp32s3 for the S3) and build again.

   Ctrl-] quits the monitor. If make doesn't work in that PowerShell, use step 3.
